# Simulador 3D - Sólidos de Revolución

Aplicación interactiva hecha con Streamlit que calcula y visualiza
volúmenes de sólidos de revolución por tres métodos:

- Discos
- Arandelas
- Cascarones cilíndricos

Incluye visualización 3D, cálculo exacto con SymPy y aproximación numérica.
